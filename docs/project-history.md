# Project History

## Iteration 1

Originally conceived as a backend application in Go following Clean Architecture principles.

After evaluating the real problem, the project direction changed.

---

## Iteration 2

The project became a data analytics platform focused on historical football statistics.

The architecture shifted toward modular analytical pipelines.

Future probabilistic models will be built on top of the statistical engine.

---

## Iteration 3

The project entered a documentation-first phase centered on the domain model, statistical questions, and glossary.

Current work is focused on defining the analytical language before implementation begins.
